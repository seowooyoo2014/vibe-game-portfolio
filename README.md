# Vibe Game Portfolio

게임을 좋아하는 초등학생의 바이브 코딩 포트폴리오입니다. 다섯 게임의 실제 화면, 플레이 링크, 컨셉, 구현에 집중한 부분과 발전 기록을 소개합니다.

## 로컬 실행

```sh
python3 build.py
python3 -m http.server 8000 -d dist
```

다섯 게임 저장소를 이 저장소와 같은 부모 디렉토리에 둡니다. `projects.json`의 `source_sha`와 각 저장소 HEAD가 일치해야 합니다. 문서와 스크린샷에 미커밋 변경이 있으면 빌드를 중단합니다. GitHub Actions도 같은 커밋을 체크아웃합니다.

## 작품 소개 갱신

1. 게임 저장소의 코드·문서·실제 스크린샷을 검증하고 커밋·push합니다.
2. `projects.json`의 해당 게임 SHA를 갱신합니다. 컨셉과 구현 설명은 확인 가능한 내용만 작성합니다.
3. 홈페이지를 빌드해 카드, 상세 문서, 이미지와 플레이 링크를 확인한 뒤 커밋·push합니다.

게임 코드는 홈페이지에서 실행하지 않으며 각 게임의 Pages 주소로 연결합니다. 공개 배포에는 GitHub 저장소의 Pages 소스를 GitHub Actions로 설정해야 합니다.

## 디자인

실제 게임 화면을 중심으로 짙은 남색과 작품별 강조색을 사용합니다. 소개는 어린 개발자의 성장 과정에 초점을 맞추되, 확인되지 않은 성취나 제작 일화는 쓰지 않습니다. 키보드 포커스, 본문 건너뛰기, 모바일 레이아웃과 동작 감소 설정을 지원합니다.
